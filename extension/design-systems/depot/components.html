      DStudio originals / Depot / v1

      A working visual vocabulary.

      Depot is a set of shelf labels for a warehouse: concrete grey and label white, narrow capitals, bin codes in bordered mono, quantities you read from a distance and stock levels with the reorder point drawn on the bar.
