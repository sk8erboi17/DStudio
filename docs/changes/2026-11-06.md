# Learn evidence retrieval and final-project scope — November 6, 2026

Learn's saved audit reported missing evidence that was already in its retained
read-source text. In the stopped private run, 103 of 122 checks were saved:
53 unverified, one contradicted, 13 supported and 36 not_factual. A separate
review of the 53 unverified items found 20 with evidence already retained for
the stated objection, 21 with partial coverage or curriculum proposals to
distinguish, nine with actual gaps in the retained references, and three needing
qualified wording. These review categories are not new passing model verdicts.
The single reported contradiction treated the whole-roadmap final project as
if it had to be completed after the first stage.

## Correction

- Evidence queries use each requested item's content, rather than a shared
  first-24-term query. Resource-attribution claims get a turn before proposed
  exercise counts. Titles and JSON metadata do not dominate retrieval.
- Selection omits duplicate link tails and demotes navigation. It retains
  literal passages, favors new query coverage over repeated common words and
  handles names, numeric separators, plural forms and limited lexical variants.
  This is bounded lexical retrieval, not translation or a semantic guarantee.
- The existing aggregate ceiling remains 14,400 evidence characters and eight
  selected sources. Capacity is shared: short useful pages can fit whole and a
  longer page receives at most 3,600 characters and 24 retained passages. Thus a
  batch with six sources can use more than its former six fixed 1,800-character
  slices, while staying inside the former eight-source maximum. No extra model
  call or automatic conversion of unverified checks is introduced.
- Preparation reads at most the first 256,000 characters of a selected source,
  yields between pages, and revalidates cancellation and run ownership. The
  index is temporary preparation for one batch; it is neither persisted nor a
  second source of truth. The existing 64-source/8M-character admission bound
  remains. Coarse source ranking still uses URLs, titles and a bounded leading
  text sample; discovery among more than eight candidates remains limited.
- Final-project checks now carry explicit whole-roadmap scope, all preceding
  stage ids and the stages still to be learned. Their instruction distinguishes
  a legitimate dependency on later skills from a real course-wide conflict.
  All stage-pair and stage/project checks remain in the plan.
- Content instructions distinguish proposed learning activities from external
  assertions and preserve recommended/required distinctions. Canonical URLs
  reach the audit request along with requested URLs.
- Receipt identities bind the actual per-job instruction and context. Old
  content and ambiguous final-project receipts remain retained but cannot
  authorize new verdicts. Unchanged stage-pair contracts can still reuse an
  exactly matching receipt. Matching revised receipts resume normally.
- Newly authored outline/stage fields exceeding existing text limits are
  refused for bounded phase recovery, rather than silently cut mid-sentence.
  Outline requests state the metadata limits. Existing saved drafts remain
  available; missing words in an earlier clipped field are not reconstructed.
