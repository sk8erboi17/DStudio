# September 6, 2026 — original Design systems, PDF reading and engine update

This is a source update, not a replacement GitHub Release app download.

## What users get

- Five original, offline Design systems: Folio, Signal, Forma, Grove and Pulse.
  The external Open Design catalog is no longer bundled or downloaded. The
  gallery supports DStudio themes and keeps previews in isolated frames.
- Design can start from a complete brief without a mandatory questionnaire.
  It recovers from incomplete tool batches without executing partial writes,
  supports linked local CSS/JS, and no longer reports token-budget exhaustion
  as a successfully completed project. Recovery is bounded and preserves files.
- Design checks now handle ordinary inline emphasis in required copy, detect
  cramped prose and missing in-page destinations, and expose actual available
  image-inspection capabilities. They do not claim every generated page is good.
- PDFs whose extracted text fits the attachment budget use the complete physical
  pages directly, avoiding an unnecessary planning-model/embedding round.
  Large, sparse or scanned documents retain their appropriate fallback paths.
  Evidence metadata stays out of visible prose; clickable sources use Poppler
  coordinates in the viewer.
- ds4 main is pinned to `f4d03f6`, with current/legacy M2 compatibility and Agent
  PLD session-rewind handling. Existing model stores and separate Laguna/Qwen
  checkouts are preserved. Laguna's incompatible Chat PLD ABI explicitly retains
  its native server; successful fallback is not a PLD acceleration claim.

## Measured results, including limitations

Matplotlib charts, plotting code and reviewed public JSON are linked from the
[README benchmark section](../../README.md#latest-measured-results).

- Engine update: 36/36 measured answers pass; 44/48 including auxiliary checks.
  No clear speed gain on the M2 Max; shared desktop load was not controlled.
- Initial Design comparison: 2/3 projects delivered in each variant, 1/3 in each
  delivered with all independent checks. Later targeted retries do not replace
  those failures. Browser checks do not establish aesthetic superiority.
- Initial private PDF library run: 75/84 expected pages/quotes retrieved;
  50/75 citation coordinate matches. Only anonymous aggregates are public.
  This is neither generated-answer accuracy nor a live viewer-modal test.

## Verification for this source publication

On macOS, rebuilt the host, signed app and four installed native engines:
main, Laguna S 2.1, Qwen3.8 and Qwen3.6. Rebuilt supported structured
Agent/Cowork/Design outputs for main and Laguna. All native executables passed
their startup/help checks; this is not a new inference qualification of all models.

Focused checks passed for engine setup, main timing/report parsing, M2 patch
lifecycle, PLD state/rewind behavior, Design runtime/recovery/gallery controls,
PDF complete-read and evidence viewer behavior, frontend functions and the
isolated macOS bundle smoke. Publication-export tests exercise actual aggregate
validation, private-field exclusion and Matplotlib rendering.

The PDF full-Chat test caught a harness-origin defect: its settings initializer
also ran in an opaque preview frame. The fix scopes initialization to the top
app origin; it does not relax the frame sandbox or suppress browser errors.
Earlier failed test receipts are retained locally.

The rebuild/publication pass does not restart the user's app, load new weights,
download models or claim Windows/CUDA coverage. Real-model evidence above comes
from the separately documented earlier runs.
