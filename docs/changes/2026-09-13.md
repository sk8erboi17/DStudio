# September 13, 2026 — engine and Qwen development checkpoint

This is a **WIP source publication**, not a fully qualified release. The current
slice is closed and the remaining implementation campaign is paused. Publishing
it does not finish the full plan, replace an installed app or certify every
model/mode/backend combination. Start with the
[plain-language status](../WORK_IN_PROGRESS.md).

## What this update contains

- **Qwen27B integration:** pinned q36 installation and verified resumable model/
  projector downloads; resident Chat, Agent and Cowork routing; native image
  tools; explicit readiness, cancellation and model ownership. Unsupported
  combinations remain explicit rather than silently changing model or context.
- **Safer engine setup and upgrades:** separately prepared builds, verified
  source/binary identity, installation-use leases, preserved projects/settings/
  weights and actual cross-version cache reuse. Installer lifetime supervision
  stops owned commands after the caller dies, including early output closure
  and commands that ignore graceful termination.
- **Versioned engine adaptations:** current ds4/V4.1 and Qwen pins, reversible
  native/Metal/terminal/cache patches, patch/build lifecycle regressions and an
  engine release-admission matrix. Unqualified candidates and missing hardware
  receipts remain visible; they do not become supported merely by compiling.
- **Agent continuation and live input:** Task Graph-backed goals, bounded
  steering, explicit completion receipts, recoverable control state and updated
  native compaction/continuation patches. The latest Qwen3.6 long-task timeout
  and summary error remain unresolved, not hidden by smaller passing tests.
- **Native model transport:** bounded structured tool messages, UTF-8 handling,
  request identity, private preparation and interruption across Agent, Cowork
  and Design consumers. A stale response cannot supply current ownership.
- **Cowork spreadsheets:** report actual data ranges and omitted/truncated
  content; distinguish a write receipt from independent readback; preserve cell
  identity and verify saved Excel results with independent readers.
- **Design and UI:** nine original offline design systems; rendered controls,
  mobile layouts and light/dark checks; model-picker/loading/readiness fixes;
  PDF source panels and live-context handling. Model-generated project
  qualification is still separate from the bundled examples' browser checks.
- **Reviewed benchmarks:** the completed Qwen27B 100-task aggregate and its
  Matplotlib chart, plus untouched regenerated Design HTML/screenshots and the
  independent radio-layout checks. Original failures and time-limit failures
  remain in the denominators. Plotting scripts and public data are included.
- **English documentation:** translated implementation/history checkpoints and
  historical engine acceptance results, current WIP guidance and updated
  contributor/third-party notes. Historical states remain dated; commands,
  evidence identities and acceptance requirements are preserved.

## Verification for publication

The initial `make check-fast` attempt failed at the settings browser test:
its expected SSD-compatible model list omitted the newly integrated V4.1 entry.
The updated assertion checks the actual rendered list, including the distinction
between expert streaming and SSD-backed Engram. Navigation must still cause no
automatic download or restart; the saved Qwen setting remains Off. The original
failed output is retained in ignored publication artifacts. The next full
attempt reached the video browser test and found another obsolete expectation:
it searched for the old text-only warning after the image-capability message
had changed. The corrected test passes and also checks that the unsent prompt
and image remain intact, with no request to the incompatible model. Neither
timeout was increased. Both failed gate attempts remain separate from the
subsequent complete rerun.

generated pages, benchmark privacy/denominator checks, and real Poppler PDF

hunk's trailing context line was trimmed to fix a whitespace warning; the

The final complete **`make check-fast` passes** (exit 0). It runs the host build,
