## Matching vision encoder downloads

Supported DeepSeek V4 Vision-Exp, V4.1 and GLM model downloads continue with the
matching native vision encoder when it is absent from the selected store. The
encoder starts only after a successful, unstopped model download, with the
selected store and file absence rechecked. Each V4.1 checkpoint keeps its own
sidecar. Text-only models and support files start no encoder. The download menu
names the additional file and status identifies the model whose encoder is
being fetched. Stop ends the remaining chain and retains an already completed
model; existing encoder files are not replaced.
