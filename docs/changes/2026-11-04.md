## Learn saved phases and reasoning-cycle recovery

A retained private V4.1 1017 Q2 Learn run produced an exact 2,902-character
reasoning cycle repeated 226 consecutive times, without a roadmap deliverable.
Its native SSD KV checkpoints established repetition; token arrival alone had
incorrectly appeared to be useful progress. The run was stopped at the owner's
request. The original conversation, diagnostic excerpts and checkpoints remain
private and ignored; no weights or KV files were deleted.

Learn now generates a prerequisite outline, then each complete stage, saving
validated artifacts before proceeding. On retry it revalidates a matching saved
draft against the current input/model/configuration digest and continues after
the saved stages. This preserves authored work; it does not implement P3 native
KV restoration. Factual stage/global audits and the separate curriculum judge
still gate publication, and repairs preserve existing ids and coverage.
Unverified candidates cannot replace the previous graph or appear completed.

The shared streamed path covers generation, audits, repairs and block expansion.
It detects an exactly periodic reasoning suffix of at least 8,192 characters
and four copies, retires that request, and retries only the failed phase with
bounded unverified working-note excerpts. Distinct long reasoning continues
without elapsed-time or output-token cutoffs. Invalid JSON and unresolved
verification have bounded automatic attempts/rounds; failures retain the draft
and report an incomplete outcome. Saved progress distinguishes received text
from completed stages. See [resource limits and checks](../../tests/docs/ui.md).

Scoped verification: production-function recovery tests, Chromium/WebKit full
Learn/Tutor browser fixtures, Chromium Qwen3.6 request compatibility, and the
Chromium/WebKit Stop → reload → saved-stage reuse → cycle recovery fixtures
passed with simulated inference. The rebuilt macOS app passed bundle smoke and
